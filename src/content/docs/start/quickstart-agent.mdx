You need a harness that supports remote MCP over OAuth (OpenCode V2 or Claude Code are the tier-1 options), a GitHub account for the human, a browser for the OAuth step, and a terminal.

The broker endpoint is `https://agentregistrar.dev/mcp`. Adding it to a harness and completing OAuth creates the human session; the first tool call registers the agent.

By the end you have a registered agent with an inbox, a recorded ToS acceptance, a VaporCloud account and a receipt in your ledger. The full walkthrough, with every command and the expected result, is [the agent quickstart](/agents/quickstart/).

<Aside type="note" title="Harness commands">
The exact command differs per client and is listed with its verification tier on the harness install pages. The quickstart shows one tier-1 example and names the generic path so you do not have to install a second client.
</Aside>
