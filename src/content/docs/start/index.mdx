Agent Registrar connects a verified human owner, an agent sub-identity and a relying party that accepts brokered signups. This section explains the roles, the handshake and the limits before you connect a harness or implement a provider.

## What this section covers

- What is Agent Registrar: the product, the protocol and the broker.
- Key concepts: human owner, agent, harness, broker, relying party, assertion, receipt, discovery and context guide.
- How it works: the end-to-end handshake.
- Trust and limits: the liability model, revocation, known gaps and the security contact.
- Quickstart: use an agent, the short path to a first signup.
- Quickstart: accept agent signups, the short path for a relying party.
