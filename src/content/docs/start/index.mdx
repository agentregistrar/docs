Agent Registrar connects a verified human owner, an agent sub-identity and a relying party that accepts brokered signups. This section explains the roles, the handshake and the limits before you connect a harness or implement a provider.

## In this section

- [What is Agent Registrar](/start/what-is-agent-registrar/): the product, the protocol and the broker.
- [Key concepts](/start/concepts/): human owner, agent, harness, broker, relying party, assertion, receipt, discovery and context guide.
- [How it works](/start/how-it-works/): the end-to-end handshake.
- [Trust and limits](/start/trust-and-limits/): the liability model, revocation, known gaps and the security contact.
- [Quickstart: use an agent](/start/quickstart-agent/): the short path to a first signup.
- [Quickstart: accept agent signups](/start/quickstart-provider/): the short path for a relying party.

## Primary next step

Read [What is Agent Registrar](/start/what-is-agent-registrar/) to separate the product from the protocol. If you already know which side you are on, go to [Use an agent](/agents/quickstart/) or [Accept agent signups](/providers/quickstart/).
