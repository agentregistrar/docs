The docs and the specification are public and Apache-2.0. Contributions follow the same evidence rules as the published pages: cite the specification or a dated verification record, keep rendered text ASCII, and do not paraphrase normative text into product pages.

## In this section

- [Docs contribution](/contribute/docs/): page templates, voice, provenance and review.
- [Spec and registry](/contribute/spec/): the specification change process and registry entries.
- [Local development](/contribute/local-development/): run the docs site, sync the spec and run the checks.

## Primary next step

Read [Docs contribution](/contribute/docs/) before opening a pull request. For the rules the pages must satisfy, see [Trust and limits](/start/trust-and-limits/).
