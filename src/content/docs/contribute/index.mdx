The docs and the specification are public and Apache-2.0. Contributions follow the same evidence rules as the published pages: cite the specification or a dated verification record, keep rendered text ASCII, and do not paraphrase normative text into product pages.

## What this section covers

- Docs contribution: page templates, voice, provenance and review.
- Spec and registry: the specification change process and registry entries.
- Local development: run the docs site, sync the spec and run the checks.
