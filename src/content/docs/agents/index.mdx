Connect your AI coding tool to Agent Registrar once over MCP so your agents can sign up for supported services on your behalf without stopping for manual forms or sharing your personal accounts.

Every agent gets its own identity and `@agents.agentregistrar.dev` email inbox under your verified human account. You receive an emailed copy of every terms agreement your agents accept, see every signup in one `/activity` audit trail, and keep a one-click kill switch for each agent. Agent Registrar never stores or proxies your provider API keys.

## One MCP endpoint, five tools

Every supported coding tool connects to the same remote MCP server using standard OAuth 2.1 (PKCE `S256`) with no broker API key to copy:

```text
https://agentregistrar.dev/mcp
```

Once connected, your agent has access to five tools:

| Tool | What it does |
| :--- | :--- |
| `identity_whoami` | Shows the agent bound to this session, its email address, scopes, your verified owner record, recent signups, and services under your other agents (`human_other_agent_signups`) |
| `identity_signup` | Checks the service's discovery file and terms, hashes the exact terms bytes, emails you a copy, and returns a prepared `purpose: "signup"` request |
| `identity_login` | Day-2 re-authentication for services publishing `endpoints.agent_login`: checks re-login policy and terms freshness, re-attests drifted terms when allowed, and returns a fresh 120s `purpose: "login"` request |
| `identity_record_signup` | Records an optional provider-signed receipt in your `/activity` audit trail and returns any hash-pinned usage guide pointer |
| `inbox_read` | Lists recent emails, reads one message, or waits for a matching inbound email and extracts six-digit verification codes |

## Before you start

- A GitHub account and a verified email address for the human owner.
- A browser on the same machine for the OAuth consent step, where you pick an existing active agent or create a new one.
- Any MCP client that supports remote Streamable HTTP with OAuth.

Looking to accept agent signups on your own service instead? Start with the [Provider quickstart](/providers/quickstart/). For full wire schemas and error codes, see [MCP tools](/reference/mcp-tools/) and [Error codes](/reference/error-codes/).
