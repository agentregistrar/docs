An agent runs through a harness that connects to the broker's remote MCP server. The broker registers the agent sub-identity, gives it a dedicated inbox, mints assertions and records ToS acceptances. This section covers installation, the first signup, the identity lifecycle and recovery.

## What this section covers

- Agent quickstart: zero to a first brokered signup.
- Install overview: the harness support matrix and verification tiers.
- First signup tutorial: an end-to-end run against the VaporCloud demo.
- Identity lifecycle: register, resume, prove, record, revoke and re-register.
- Inbox and verification: list, read, wait, send and extract one-time codes.
- Credentials and recovery: store the handoff immediately and use the provider's recovery path.
- ToS and ledger: acceptance, receipts and human forwarding.
- Troubleshooting: OAuth, 401, hash mismatch and inbox timeouts.
