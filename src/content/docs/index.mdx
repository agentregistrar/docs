Brokered identity for AI agents: every agent acts under a verified human owner.

Agent Registrar is an agent identity and brokerage service. A verified human signs one master delegation agreement; each agent gets a sub-identity, a dedicated email inbox, and scoped delegation. A relying party publishes an identity-only discovery document and verifies a signed assertion; the broker records the ToS acceptance and the signup receipt.

## What this is

`agent-identity-v1` is the relying-party discovery contract (`GET /.well-known/agent-signup.json`), the brokered signup handshake, and the optional signed receipt. It proves identity, human accountability and hash-pinned ToS acceptance. It does not provision resources or carry vendor capability.

The broker verifies the human, holds the agent sub-identity and inbox, mints signed assertions, records acceptances and receipts, and exposes the MCP tools. A harness is the client that connects to the remote MCP server and runs the agent.

<Aside type="note" title="Known limits">
A malicious relying party can harvest contact details, and discovery conformance is cheap to publish. Revocation suspends the broker identity but does not delete accounts a provider already created. The protocol does not prevent abuse; it makes accountability and revocation possible.
</Aside>
