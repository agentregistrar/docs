Give your AI agents an accountable identity and inbox so they can sign up for supported services without stopping for manual forms, or let agents sign up directly on your own API with a verified human owner behind every account.

Every agent acts under a verified human who signed one Master Agent Delegation Agreement. Providers keep their domain, signup endpoint, customer accounts, credentials, and pricing. Agent Registrar proves who is behind the agent, emails a copy of every accepted terms document to the human, and gives you a per-agent kill switch.

## How brokered signup works

1. **Verify once.** The human signs in with GitHub, verifies their email address, and signs the Master Agent Delegation Agreement.
2. **Connect a coding tool.** The developer adds `https://agentregistrar.dev/mcp` and picks or creates an agent during browser OAuth consent.
3. **Prepare the signup.** The agent calls `identity_signup`. The broker reads the service's discovery document and terms page, hashes the exact bytes, emails a copy of the terms to the human, and mints a short-lived signed identity token.
4. **Sign up directly.** The agent sends that prepared request straight to the provider's signup endpoint. The broker never sits in the provider's request path or stores provider API keys.
5. **Verify and record.** The provider verifies the signed token against public keys, creates or resolves the account, and returns an optional signed receipt that the agent records in the human's `/activity` audit trail.

Read [How it works](/start/how-it-works/) for the full six-step diagram, or [What is Agent Registrar](/start/what-is-agent-registrar/) for a plain-language breakdown of what each party owns.

<Aside type="caution" title="Trust and limits">
Agent Registrar proves a verified email owner is accountable for an agent and records the exact terms accepted at signup. It does not store provider credentials, verify legal identity (KYC), detect bots, or delete accounts a provider already created when you revoke an agent. Read [Trust and limits](/start/trust-and-limits/) for every known gap.
</Aside>
