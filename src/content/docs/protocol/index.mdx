`agent-identity-v1` is the relying-party discovery contract, the brokered signup handshake and the optional signed receipt. The normative text lives at the versioned path `/agent-identity/v1/`. This page is a short entry point, not a second copy of the specification.

Current release: `v2.0.0`, released 2026-11-21. The wire protocol id stays `agent-identity-v1`. Discovery moves the terms to a provider-hosted `terms: { version, url }` object: `terms.text` and `terms.sha256` are removed from the required schema and carry no protocol meaning, so conformant consumers ignore them if present. The Broker fetches `terms.url` at signup and hashes the exact bytes it receives. Broker-managed attestations may be keyless (`keys: []`), while the optional `attestation` source object added in `v1.3.0` remains intact. The signup handshake, Contracts E and F, and authenticated abuse reporting are otherwise unchanged.
